✦ 내 계정으로 쓰기

이 사이트는 주인 한 명의 계정만 동기화돼요. 친구도 자기 계정으로 쓰려면 저장소를 Fork(복사)해서 나만의 사이트를 만들면 됩니다. 쿠키·UID는 내 저장소의 Secrets에만 들어가서 원래 주인도, 다른 누구도 볼 수 없어요. 휴대폰 브라우저로 10분쯤 걸립니다(GitHub 앱은 설정 메뉴가 없어서 안 돼요).

아직 계정이 없으면 1단계부터 하세요.

  1. GitHub 가입·로그인

    브라우저로 github.com에 가입(무료)하고 로그인합니다. 가입은 만 13세 이상만 할 수 있어요. 화면이 좁아 메뉴가 안 보이면 브라우저 메뉴에서 데스크톱 사이트를 켜세요.

    가입하기로그인

  2. 저장소 Fork 하기

    아래 버튼 → 이름은 Genshin 그대로 두고 초록 Create fork를 누릅니다. 내 계정에 똑같은 저장소가 생겨요.

    Fork 하러 가기

  3. 내 사이트 켜기 (GitHub Pages)

    내 저장소 → Settings → 왼쪽 Pages → Source: Deploy from a branch, Branch: main / (root) → Save. 1~2분 뒤 내 사이트 주소가 열립니다.

    Pages 설정 열기

  4. 자동 실행 켜기 (Actions)

    Fork한 저장소는 자동 실행이 꺼진 채로 시작해요. 내 저장소 → Actions 탭 → 초록 I understand my workflows, go ahead and enable them. 그다음 왼쪽 hoyolab-sync를 눌러 Enable workflow 버튼이 보이면 그것도 누르세요(3시간마다 자동 동기화).

    Actions 열기

  5. 내 UID (와 쿠키) 넣기

    내 저장소 → Settings → Secrets and variables → Actions → New repository secret.

    • 이름 GENSHIN_UID, 값: 원신 UID. 이것만 넣으면 게임 프로필의 캐릭터 쇼케이스(최대 12명, 캐릭터 상세 정보 표시 켜기)를 받아요.
    • (선택) 보유 캐릭터 전부를 받으려면 Secret을 하나 더: 이름 HOYOLAB_COOKIE, 값 ltoken_v2=값; ltuid_v2=값; ltmid_v2=값. 쿠키 복사 방법은 메인 화면의 연동 방법에 있어요.
    Secrets 열기

  6. 처음 한 번 실행

    hoyolab-sync → 오른쪽 Run workflow → 초록 Run workflow. 1~2분 뒤 새로고침해서 ✅면 성공이에요. ❌면 그 실행을 눌러 Fetch account data의 오류 문장을 확인하세요(쿠키 만료·형식 오류가 대부분).

    hoyolab-sync 열기

  7. 내 사이트에서 동기화

    아래 내 사이트를 열고 HoYoLAB 동기화를 누르면 내 캐릭터가 채워집니다. 홈 화면에 추가해서 앱처럼 쓰세요. 이 사이트(원본)에 넣었던 기록은 내 사이트로 옮겨지지 않아요.

    내 사이트 열기

티어표·도감 업데이트는?

  • 내 저장소의 hoyolab-sync가 돌 때마다 원본의 새 티어표·도감·지도 자료를 자동으로 합쳐 와요. 내 계정 파일은 그대로 둡니다.
  • 실행 결과에 "자동으로 합치지 못했습니다" 경고가 뜨면, 내 저장소 첫 화면의 Sync fork → Update branch를 한 번 눌러 주세요.

안전하게 쓰기

  • 쿠키는 내 저장소의 Secrets에만 넣으세요. 원본 주인을 포함해 누구에게도 보내지 말고, 채팅·메모 공유·다른 사이트에 붙여 넣지 마세요. 쿠키는 계정 열쇠예요.
  • Secrets 값은 넣은 뒤 아무도(나 자신도) 다시 볼 수 없고, 결과 파일에도 들어가지 않아요.
  • 대신 받아 온 캐릭터 정보(account/hoyolab.json — 닉네임·모험 등급·캐릭터·성유물)는 공개 저장소라 누구나 볼 수 있어요. UID는 원래 공개 정보예요.
  • 그만 쓰려면 Secrets에서 HOYOLAB_COOKIE를 지우거나 HoYoLAB에서 로그아웃하면 쿠키가 바로 쓸모없어져요. 저장소째 지우려면 Settings 맨 아래 Delete this repository.
